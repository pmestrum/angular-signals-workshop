# Angular signals workshop

A small webshop (Angular 22, 800 x 600) that starts without signals and is converted step by step to a fully signal based, zoneless app.

- Workshop instructions: [workshop.md](workshop.md) (English), [workshop.nl.md](workshop.nl.md) (Nederlands)
- Vocabulary: [CONTEXT.md](CONTEXT.md)

```bash
npm install
git checkout -b workshop step-0
npm start
```

The tags `step-0` to `step-8` hold the starting point and the solution of every step. `main` is the end result (`step-8`).
